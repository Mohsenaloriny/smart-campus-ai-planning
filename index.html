Part I: Campus Route Planner & Search Mastery

🏛️ 11 Locations & 18 Weighted Pathways

The campus is represented as a formal weighted graph $G = (V, E, W)$ embedded in a 2D Euclidean coordinate space. Every building has physical Cartesian coordinates $(x, y)$ on a 100-meter scale to allow exact distance calculations.

Critical Rubric Requirement Verified:

"At least one case where the shortest path in number of edges is NOT the lowest-cost path."

• Route A (Direct Boulevard via Library): MG ➔ LIB ➔ CS = 2 Hops, Cost = 18.0
• Route B (Optimal via Admin & Eng): MG ➔ ADM ➔ ENG ➔ CS = 3 Hops, Cost = 15.0

👉 Theoretical Insight: Breadth-First Search (BFS) would incorrectly select the 2-hop route because it only counts edge transitions. UCS and A* evaluate actual additive costs $g(n)$, successfully guaranteeing the optimal cost of 15.0.

📐 Heuristic Design & Formal Mathematical Proofs

The heuristic function estimates remaining distance using 2D Euclidean straight-line distance:

h(n) = ||p_n - p_Goal||_2 = sqrt( (x_n - x_Goal)^2 + (y_n - y_Goal)^2 )

Proof 1: Admissibility ($h(n) \le h^*(n)$)

1. Condition: A heuristic is admissible if $\forall n, h(n) \le h^*(n)$, where $h^*(n)$ is the true optimal cost from node $n$ to goal $G$.
2. In Euclidean geometry, the straight-line segment connecting two points represents the absolute infimum of physical path lengths between them.
3. Because physical transit through campus walkways is constrained by corridors, walls, and corners, any real walkable route along edges satisfies $\text{Road Distance } h^*(n) \ge \text{Straight-line Distance } h(n)$.
4. Therefore, $h(n) \le h^*(n)$ strictly holds, guaranteeing that A* search will always discover the mathematically optimal path.

Proof 2: Consistency / Monotonicity

1. Condition: $h(n) \le c(n, a, n') + h(n')$ for every successor $n'$.
2. By the Triangle Inequality in metric spaces, for any node $n$, neighbor $n'$, and goal $G$: $\|p_n - p_G\|_2 \le \|p_n - p_{n'}\|_2 + \|p_{n'} - p_G\|_2$.
3. Since edge cost $c(n, a, n') \ge \|p_n - p_{n'}\|_2$, substitution yields $h(n) \le c(n, a, n') + h(n')$.
4. Result: $f(n)$ values along any path are monotonically non-decreasing, ensuring that once a node is expanded, A* never needs to re-expand it.

🎯 Direct Academic Answers for CLO2 Rubric

1. Why is UCS an uninformed optimal search strategy?
Uninformed: UCS has no heuristic intuition or knowledge of the goal's relative coordinates. It prioritizes states purely based on historical path cost $g(n)$.
Optimal: Because edge costs are strictly positive ($c > 0$), UCS expands states in monotonically increasing order of $g(n)$. Testing the goal upon dequeuing/expansion guarantees that the first path popped for the goal has minimum possible cost.
2. Why is A* an informed search strategy?
A* evaluates states using $f(n) = g(n) + h(n)$, combining actual past cost with an informed forward estimate $h(n)$. This biases search in the direction of the goal, pruning off-target branches.
3. What information does our heuristic use?
It uses the 2D Cartesian coordinates $(x, y)$ of campus facilities to compute straight-line Euclidean distance: $h(n) = \sqrt{(x_n - x_G)^2 + (y_n - y_G)^2}$.
4. Why is our heuristic admissible?
In Euclidean space, a straight line is the absolute minimum distance between two points. Physical campus pathways involve turns and corridors, so $h^*(n) \ge h(n)$ always holds. It never overestimates.
5. Why do UCS and A* expand different numbers of states (9 vs 4)?
UCS expands symmetrically in concentric ripples, wasting expansions on irrelevant nodes (`PRK`, `MED`, `SC`, `CAF`) simply because their cost from start was low. A* adds $h(n)$, which heavily penalizes nodes heading away from the goal, creating a focused beam directly to `CS`.

Dr. Fayçal Hamdi's "Live Understanding Check" Simulator

During the live project demonstration, the instructor will modify a parameter and ask you to predict the algorithmic behavior before running the code. Here are the exact predicted responses:

⚡ Question 1: "What happens if I increase edge cost ADM ➔ ENG from 6 to 12?"
Prediction: Path via ADM increases from $15.0$ to $5 + 12 + 4 = \mathbf{21.0}$. Both UCS and A* will abandon this route and re-route via the Central Library: `MG ➔ LIB ➔ CS` with cost $\mathbf{18.0}$, demonstrating cost-based dynamic adaptation!
⚡ Question 2: "What happens if I set the heuristic h(n) = 0 for all nodes?"
Prediction: $f(n) = g(n) + 0 = g(n)$. A* degenerates exactly into Uniform-Cost Search! It will expand the identical 9 states in the identical sequence and return the optimal path with cost 15.0.
⚡ Question 3: "What happens if we multiply the heuristic by 3 (Overestimated Heuristic)?"
Prediction: The heuristic becomes inadmissible ($h(n) > h^*(n)$). A* acts like Greedy Best-First Search; it may run faster (fewer expansions), but it loses the guarantee of returning the optimal cost path!
⚡ Question 4: "Why does the goal test happen when a node is removed from Frontier, not when generated?"
Prediction: If we test when generated, we might discover the goal via a high-cost path first (e.g. 2 hops) before the lower-cost path (3 hops) is evaluated. Testing on removal guarantees that all cheaper candidate paths have already been explored!
